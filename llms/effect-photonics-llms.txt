# EFFECT Photonics

> EFFECT Photonics is an optical-semiconductor company in Eindhoven, the Netherlands, spun out of
> Eindhoven University of Technology, that designs and manufactures coherent optical transceiver
> subsystems and monolithically integrated Indium Phosphide photonic integrated circuits — including
> its pico and nano Integrable Tunable Laser Assemblies for 100G, 400G and 800G coherent links.
> It operates **no developer API programme**: no developer portal, no published documentation, no
> OpenAPI, no SDK, no pricing and no sandbox. What it does run is a live WordPress REST API on its
> corporate website, with a publicly readable optical-product catalogue, a first-party `effect/v1`
> namespace, and two OAuth-guarded Model Context Protocol servers.

This file was generated by API Evangelist on 2026-08-12 from the provider's own live surface.
EFFECT Photonics does not publish an llms.txt — https://effectphotonics.com/llms.txt returns HTTP 404.

## What is callable

- [REST route discovery](https://effectphotonics.com/wp-json/): the self-describing index of all 290
  routes across 13 namespaces. Anonymous, HTTP 200. Everything in this profile derives from it.
- [Product catalogue](https://effectphotonics.com/wp-json/wp/v2/product): coherent optical laser
  assemblies, each carrying term references into seven hardware taxonomies — product line, output
  power, form factor, tuning range, target application, operating temperature grade and management
  interface (OIF ITLA MSA 01.3). Anonymous read.
- [FAQ collection](https://effectphotonics.com/wp-json/wp/v2/faq): the company's published lead
  times, minimum order quantities, incoterms, export-control posture and RoHS/REACH/IEC 60825-1
  compliance statements. Anonymous read, 29 entries.
- [Newsroom](https://effectphotonics.com/wp-json/wp/v2/posts): 144 dated press releases and technical
  articles. Anonymous read. RSS at https://effectphotonics.com/feed/.
- [Careers, events, partners, team](https://effectphotonics.com/wp-json/wp/v2/types): first-party
  custom post types, all anonymously readable.
- [effect/v1](https://effectphotonics.com/wp-json/effect/v1): the site's own namespace —
  `POST /careers/sync` (gated, HTTP 401) and `GET|POST /glb-positions/{id}` for the product
  visualiser's 3D models.
- [MCP servers](https://effectphotonics.com/wp-json/mcp): `mcp-oauth-server` and
  `mcp-adapter-default-server`. Both return **HTTP 401** to an anonymous `tools/list`. The tool set
  is not publicly enumerable.

## Authentication

- Published content reads with **no credential**.
- Privileged reads and all writes need a WordPress application password (HTTP Basic) or a cookie plus
  `X-WP-Nonce`.
- The `mcp` namespace needs OAuth 2.1: authorization_code + PKCE `S256`, single scope `mcp`, public
  clients only.
  - [Authorization server metadata (RFC 8414)](https://effectphotonics.com/.well-known/oauth-authorization-server) — HTTP 200
  - [Protected resource metadata (RFC 9728)](https://effectphotonics.com/.well-known/oauth-protected-resource) — HTTP 200

## Conventions

- Pagination: `page`, `per_page` (max 100), `offset`; `X-WP-Total` and `X-WP-TotalPages` response headers.
- Payload control: `_fields`, `_embed`, `_envelope`, `context` (`view`|`embed`|`edit`).
- Errors: `{"code","message","data":{"status"}}` — the WordPress envelope, **not** RFC 9457.
- No idempotency key. No published rate limits and no `RateLimit-*` or `Retry-After` headers.
- Taxonomy filters take **term ids**, not slugs — resolve the vocabulary first.
